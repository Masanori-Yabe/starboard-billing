# StarBoard 請求管理システム

マッチング費（紹介料）の2回払い請求を、案件（人材1名 × 受入企業1社）の進捗から自動導出する管理画面。

- `index.html` … 管理画面
- `manual.html` … 使い方マニュアル

データは Supabase に保存され、ログインしたユーザーのみ閲覧・編集できる（全テーブルで RLS 有効）。
このリポジトリに含まれるキーはブラウザ公開前提の publishable key のみで、単体ではデータを読み出せない。

サーバー側スクリプト（Chatwork 連携・通知）は社内 Mac 上で稼働し、このリポジトリには含めない。
